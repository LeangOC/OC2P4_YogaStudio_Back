## Installation,lancement et tests

### 1. Clone
> git clone https://github.com/LeangOC/OC2P4_YogaStudio_Back.git

###  Pré-requis pour la base mysql
- Docker-Desktop lancé en local
- sourcer l' environemment .env 

### 3. Démarrage de l'application :
> mvn spring-boot:run

### 4. Lancement des tests
> mvn clean test

rapport coverage Jacoco : target/site/jacoco/index.html
